# Vorlage für das Power-BI-Projekt

`CY24SU10.json` ist das Basis-Design („base theme“), das Power BI Desktop beim Speichern eines Projekts unter
`StaticResources/SharedResources/BaseThemes/` ablegt. Die Datei stammt aus
[MicrosoftLearning/mslearn-fabric](https://github.com/MicrosoftLearning/mslearn-fabric)
(`Allfiles/VSCode-Development/…/BaseThemes/CY24SU10.json`), Copyright (c) 2023 Microsoft, MIT-Lizenz.

`sternschema.py` kopiert sie unverändert in das erzeugte Projekt. Die Farben des Berichts kommen aus dem eigenen
Design `Cockpit_Pastell.json`, das darüber liegt.
